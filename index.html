Features

ALL PAGES
Open Menu
L2 + OPTIONS

Hold L2 and press Options to open the menu. Use UP/DOWN to navigate, CROSS to select, CIRCLE to go back, and LEFT/RIGHT to scroll between pages inside a category.

PAGE 1 — TCM
R2 Spam
L2 + R2

Toggles rapid R2 spam. Rapidly presses R2 automatically for continuous trigger actions.

PAGE 1 — TCM
Square Spam
L2 + SQUARE

Toggles rapid Square button spam for quick in-game actions.

PAGE 1 — TCM
X Spam
L2 + CROSS

Toggles rapid X / Cross button spam for quick in-game or menu actions.

PAGE 2 — BO7 / WARZONE
Anti-Recoil, AA & More
MENU ONLY

Anti-Recoil, Bull Tracker V4, Triple Aim V4, Strafe Assist, Shoot Spam, Ability Spam and Move Spam. All features are configured and toggled through the menu only — no in-game hotkeys.

PAGE 3 — CW
DPAD Swap
L2 + LEFT

Swaps the DPAD Up and Left inputs for Cold War movement remapping.

PAGE 4 — BO3
R2 Hold
L2 + LEFT

Holds R2 down automatically. Great for continuous firing or holding actions in BO3.

PAGE 4 — BO3
Liquid Divinium
L2 + RIGHT

Taps X / Cross automatically with a timed interval for BO3 For Liquid Divinium.

PAGE 4 — BO3
Crypto Keys
L2 + R3

Double taps X / Cross automatically with a timed interval for BO3 For Crypto Keys.

PAGE 4 — BO3
Aim Spam
L2 + DOWN

Spams the L2 trigger automatically for BO3.

PAGE 5 — 2K
Shooting, Misc & More
MENU ONLY

Shooting: Button Rhythm, Tempo, Stability. Fade: Fade Toggle, Fade Tempo, Turbo Shot (Hop Jumper / Turbo Fade). Misc: Button Remap, QuickStop, Dunk Meter, Defense Assist, Infinity Sprint — all configured through the menu only.

PAGE 6 — ROBLOX
Blade Ball — AutoClicker
L2 + R2

Inside the Blade Ball sub-menu. AutoClicker is enabled by default — hold R2 to activate clicks while in Blade Ball.

PAGE 7 — GTA ONLINE
Fast CEO
L1 + CROSS

Opens the interaction menu and automatically navigates to register as CEO. One button quick register.

PAGE 7 — GTA ONLINE
Body Armor
L1 + CIRCLE

Opens the interaction menu and automatically equips Body Armor.

PAGE 7 — GTA ONLINE
Ammo
L1 + TRIANGLE

Opens the interaction menu and automatically purchases Ammo.

PAGE 7 — GTA ONLINE
Snacks
L1 + SQUARE

Opens the interaction menu and automatically uses Snacks to restore health.

PAGE 7 — GTA ONLINE
RPG Self
R1 + TOUCHPAD

Holds L1 to open the weapon wheel, navigates to the RPG, looks down and fires. Quick self-kill for a fast respawn.

Tips & Usage

  • Hold L2 while pressing the matching button to toggle features on pages 1–6 without affecting normal gameplay.
  • To switch between game pages open the menu with L2 + Options, navigate to the game name and press Cross to select it. This is the only way to switch pages.
  • GTA macros automatically open and navigate the interaction menu for you. Make sure you are on foot and not in a cutscene before triggering them.
  • RPG Self opens the weapon wheel, navigates to the RPG and fires. Best used when you need a quick self-kill respawn.
  • BO7-WZ and 2K have no hotkeys — all settings are configured through the menu only. Changes save automatically when you close the menu.
  • Check the LED on your Cronus device for instant visual feedback of what is currently active.
  • GTA features are PS5 Online only. All other pages work on PS4/5.
